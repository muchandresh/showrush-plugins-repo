# Community Plugins Repository

> Ad-free streaming extensions for the app — inspired by plugins for Cloudstreme and nuvio.

## 📦 Install

Add this repository URL in the app: **Settings → Extensions → Add Repository**

```
https://raw.githubusercontent.com/muchandresh/showrush-plugins-repo/master/repository.json
```

## 🛠️ Usage

- Browse available plugins in the extensions menu
- Enable/disable per profile
- Each plugin provides movies, TV shows, or anime streams

## 📄 repository.json Format

```json
{
  "id": "com.showrush.community",
  "name": "Community Repo",
  "plugins": [...]
}
```
